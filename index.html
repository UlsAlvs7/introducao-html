Início

O HTML (Hypertext Markup Language) é a linguagem de marcação padrão para criar páginas da web. Ele é usado para estruturar o conteúdo da página, como texto, imagens, links e outros elementos. O HTML utiliza tags para definir a estrutura e a formatação do conteúdo.

Sobre

O HTML foi criado por Tim Berners-Lee em 1990, com o objetivo de facilitar o compartilhamento de informações na internet. O principal impacto do HTML foi permitir a criação de páginas web dinâmicas e interativas, tornando a internet mais acessível e útil para os usuários. Na epoca foi um grande avanço tecnológico pois permitiu uma melhor organização e apresentação de conteúdos na web.

Principais Elementos do HTML

O HTML possui uma variedade de elementos que podem ser utilizados para estruturar e formatar o conteúdo de uma página web. Alguns dos principais elementos incluem:

  • <h1> a <h6>: Elementos de cabeçalho, usados para definir títulos e subtítulos.
  • <p>: Elemento de parágrafo, usado para agrupar blocos de texto.
  • <a>: Elemento de link, usado para criar hyperlinks para outras páginas ou recursos.
  • <img>: Elemento de imagem, usado para exibir imagens na página.
  • <ul> e <ol>: Elementos de lista, usados para criar listas não ordenadas e ordenadas, respectivamente.
  • <div>: Elemento de divisão, usado para agrupar outros elementos e aplicar estilos ou scripts.
  • <span>: Elemento em linha, usado para aplicar estilos a partes específicas do texto.

Como destacar o texto

O elemento <mark> é usado para destacar o texto, geralmente aplicando um fundo amarelo ao conteúdo selecionado. Ele é útil para chamar a atenção para informações importantes ou relevantes.

Exemplo de uso do elemento<mark>:

Como sublinhar o texto

O elemento <u> é usado para sublinhar o texto, aplicando uma linha horizontal abaixo do conteúdo selecionado. Ele é útil para enfatizar palavras ou frases específicas.

Principais Atributos

O HTML possui diversos atributos que podem ser aplicados aos elementos para modificar seu comportamento ou aparência. Alguns dos principais atributos incluem:

  • id: Atribui um identificador único a um elemento, permitindo que ele seja referenciado por CSS ou JavaScript.
  • class: Atribui uma ou mais classes a um elemento, permitindo que ele seja estilizado com CSS.
  • src: Especifica o caminho de um recurso externo, como uma imagem ou script.
  • alt: Fornece uma descrição alternativa para imagens, útil para acessibilidade e SEO.
  • href: Especifica o destino de um link.
  • target: Define onde o link será aberto (por exemplo, em uma nova aba).

Os 3 principais inputs

O HTML oferece diversos tipos de campos de entrada (inputs) que permitem aos usuários interagir com formulários e enviar informações. Alguns dos principais tipos de inputs incluem:

  • input type="text": Permite a entrada de texto em uma única linha.
  • input type="number": Permite a entrada de números, com validação automática para garantir que apenas valores numéricos sejam aceitos.
  • input type="color": Permite a seleção de uma cor usando um seletor de cores.
