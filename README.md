
# Introdução ao HTML

Meu primeiro projeto prático utilizando HTML, desenvolvido durante meus estudos de desenvolvimento web na plataforma DIO (Digital Innovation One).

## 📌 Sobre o projeto

Este projeto consiste na criação de uma página web em formato de blog educativo, com o objetivo de apresentar conceitos fundamentais do HTML por meio de explicações e exemplos práticos.

A proposta é aplicar os conhecimentos adquiridos durante as aulas, explorando diferentes elementos, tags e atributos utilizados na construção de páginas web.

## 🎯 Desafio de projeto

Este projeto foi desenvolvido como parte do desafio **Criar Uma Página Web Utilizando as Tags Aprendidas**, disponível na formação HTML Developer da DIO.

🔗 [Acessar o desafio original na DIO](https://web.dio.me/project/criar-uma-pagina-web-utilizando-as-tags-aprendidas/learning/e2c3c07c-6b90-413b-ac5b-ae49a61aed9a)

## 📚 Conteúdos abordados

Durante o desenvolvimento da página, foram explorados os seguintes conceitos:

- Estrutura básica de um documento HTML.
- Títulos e subtítulos (`h1` até `h6`).
- Parágrafos (`p`).
- Formatação e destaque de textos (`strong`, `u`, `mark`).
- Texto em superíndice (`sup`).
- Links e navegação por âncoras (`a`).
- Imagens e legendas (`img`, `figure`, `figcaption`).
- Listas ordenadas e não ordenadas (`ol`, `ul`, `li`).
- Principais atributos HTML (`id`, `class`, `src`, `alt`, `href`, `target`).
- Campos de entrada (`input`).
- Elementos de organização e estruturação do conteúdo.

## 🛠️ Tecnologias utilizadas

- HTML5

## 💻 Como executar o projeto

Não é necessário instalar nenhuma dependência ou ferramenta adicional.

1. Faça o download ou clone este repositório.
2. Acesse a pasta do projeto.
3. Abra o arquivo `index.html` em qualquer navegador.

## 🎓 Objetivo de aprendizagem

O principal objetivo deste projeto é consolidar os conhecimentos iniciais de HTML por meio da prática, compreendendo como os elementos e atributos da linguagem são utilizados para estruturar e organizar o conteúdo de uma página web.
