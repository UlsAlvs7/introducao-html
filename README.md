
# Introdução ao HTML

Meu primeiro projeto prático de desenvolvimento web, criado para estudar e aplicar os conceitos fundamentais do HTML.

## Sobre o projeto

Este projeto consiste em um blog educativo com explicações e exemplos práticos sobre a estruturação de páginas web utilizando HTML.

## Conteúdos abordados

- Estrutura básica de um documento HTML
- Títulos e parágrafos
- Formatação e destaque de textos
- Links e navegação por âncoras
- Imagens e legendas
- Listas ordenadas e não ordenadas
- Principais atributos HTML
- Campos de entrada (inputs)
- Elementos semânticos

## Tecnologia utilizada

- HTML5

## Como executar

1. Clone ou baixe este repositório.
2. Abra a pasta do projeto.
3. Execute o arquivo `index.html` em seu navegador.

## Objetivo

Este projeto faz parte da minha jornada de aprendizado em Ciência da Computação e desenvolvimento web.

A proposta é aprender na prática, construir uma base sólida em HTML e evoluir futuramente para CSS e JavaScript.
